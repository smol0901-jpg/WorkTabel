# WorkTable — Система управления питанием

## Описание
Веб-приложение для управления питанием в общепите с интеграцией Telegram бота.

## Архитектура
- **Frontend**: React (Netlify)
- **Backend**: Node.js API (Netlify Functions)
- **Database**: Supabase (PostgreSQL)
- **Telegram Bot**: для уведомлений и отправки в группу
- **GitHub**: CI/CD и хранение кода

---

## Функционал

### Партнёры (самостоятельная регистрация)
- Регистрация с логином и паролем
- Просмотр меню на неделю (5/2 или 7/0)
- Просмотр меню на сегодня/завтра
- Указание количества человек на период
- История своих заказов

### Администратор
- Активация/деактивация партнёров
- Загрузка меню через Google Таблицу
- Мониторинг всех заявок
- Отправка данных в Telegram группу

### Telegram Бот
- Уведомления о новых заявках
- Отправка меню + количества человек в группу
- Темы в группе:
  - 📜 История (лого, все изменения, действия, отправки)
  - 📝 Заявки
  - ⏳ Ожидание
  - ✅ Согласования

---

## Режимы меню
- **5/2**: 5 рабочих дней, 2 выходных (период 10 дней)
- **7/0**: 7 дней без выходных (период 14 дней)

## Структура БД (Supabase)

### Таблица: users
| Поле | Тип | Описание |
|------|-----|----------|
| id | uuid | ID пользователя |
| login | text | Логин (уникальный) |
| password_hash | text | Хэш пароля |
| name | text | Имя партнёра |
| role | text | 'partner' или 'admin' |
| is_active | boolean | Активирован админом |
| created_at | timestamp | Дата регистрации |

### Таблица: menus
| Поле | Тип | Описание |
|------|-----|----------|
| id | uuid | ID меню |
| date | date | Дата |
| day_type | text | 'weekday' или 'weekend' |
| breakfast | text | Завтрак |
| lunch | text | Обед |
| dinner | text | Ужин |
| mode | text | '5/2' или '7/0' |

### Таблица: orders
| Поле | Тип | Описание |
|------|-----|----------|
| id | uuid | ID заказа |
| user_id | uuid | ID партнёра |
| start_date | date | Дата начала |
| end_date | date | Дата окончания |
| person_count | integer | Количество человек |
| status | text | 'pending', 'confirmed', 'sent' |
| created_at | timestamp | Дата создания |

### Таблица: history
| Поле | Тип | Описание |
|------|-----|----------|
| id | uuid | ID записи |
| action | text | Действие |
| details | jsonb | Детали |
| created_at | timestamp | Дата |
