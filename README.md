# TimeTrack Pro

**Система учёта рабочего времени для малого бизнеса**

---

## 📋 Описание

TimeTrack Pro — это простая и мощная система для учёта рабочего времени сотрудников. Позволяет отслеживать время работы, формировать отчёты и анализировать продуктивность команды.

### Возможности

- ✅ Учёт рабочего времени сотрудников
- ✅ Табель учёта с автоматическим расчётом
- ✅ Управление сотрудниками и проектами
- ✅ Гибкая система отчётов
- ✅ Простая авторизация по PIN
- ✅ SQLite — не требует настройки БД
- ✅ Веб-интерфейс — работает в браузере

## ⚙️ Использование

### Вход в систему
- Открой http://localhost:5000
- Введи PIN: **1234**

### Основные разделы

| Раздел | Описание |
|--------|----------|
| **Dashboard** | Главная панель с сегодняшними записями и статистикой |
| **Сотрудники** | Добавление и управление сотрудниками |
| **Отчёты** | Формирование отчётов за период |
| **Настройки** | Настройка рабочего времени и перерывов |

### Как начать отслеживать время

1. Перейди на **Dashboard**
2. Выбери сотрудника из списка
3. Заполни форму:
   - Дата
   - Время начала
   - Время окончания
   - Перерыв (минуты)
   - Описание задачи
   - Проект
4. Нажми **Добавить запись**

## 🔧 Настройка

### Изменение PIN

В файле `app.py` измени значение:

```python
ADMIN_PIN = '1234'  # Замени на свой PIN
```

### Настройка рабочего времени

В разделе **Настройки** можно изменить:
- Время начала рабочего дня
- Время окончания
- Длительность перерыва

---

## 📊 Отчёты

Система формирует автоматические отчёты:

- **За день**: сколько часов отработал каждый сотрудник
- **За неделю**: суммарное время по сотрудникам
- **За месяц**: стоимость работы каждого сотрудника
