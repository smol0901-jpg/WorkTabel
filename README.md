# FoodApp - Система управления общепитом

## 🚀 Развёртывание на Vercel

Это веб-приложение полностью готово для деплоя на Vercel.

### Быстрый старт


```bash
# Установка зависимостей
pip install -r requirements.txt

# Запуск локально
python app.py
```

Открой http://localhost:5000

## 🌐 Деплой на Vercel

1. Создай аккаунт на vercel.com
2. Подключи GitHub репозиторий
3. Vercel автоматически определит Flask приложение
4. Готово!

Или через CLI:

```bash
npm i -g vercel
vercel
```
