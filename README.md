# ⏱ TimeTrack Pro

**Профессиональная система учёта рабочего времени для малого бизнеса**

---

## 📋 Описание

TimeTrack Pro — это готовое к использованию веб-приложение для учёта рабочего времени сотрудников. Не требует сложной настройки, работает "из коробки" на SQLite.

### Ключевые возможности

| Возможность | Описание |
|-------------|----------|
| 👥 Учёт сотрудников | Добавление, редактирование, удаление сотрудников с привязкой к должности и ставке |
| ⏰ Учёт времени | Фиксация начала/конца работы, автоматический расчёт часов |
| 📊 Табель учёта | Автоматический подсчёт отработанных часов за день/неделю/месяц |
| 💰 Расчёт зарплаты | Автоматический расчёт стоимости работы на основе почасовой ставки |
| 📈 Отчёты | Гибкая система отчётов с детализацией по сотрудникам и проектам |
| 🎨 Веб-интерфейс | Современный UI на Bootstrap — работает в любом браузере |
| 🔒 PIN-авторизация | Простая и надёжная защита без сложных паролей |

## ⚙️ Использование

### Первый запуск

1. Запусти `python app.py`
2. Открой http://localhost:5000
3. Введи PIN: **1234**
4. Система готова к работе!

### Основные разделы

#### 📊 Dashboard
Главная страница с:
- Статистикой (сотрудники, записи, проекты, часы за неделю)
- Формой добавления новой записи времени
- Списком сегодняшних записей с возможностью остановки таймера

#### 👥 Сотрудники
Управление сотрудниками:
- Добавление нового сотрудника (имя, должность, ставка/час)
- Просмотр списка всех сотрудников
- Удаление сотрудника (мягкое удаление, данные сохраняются)

#### 📈 Отчёты
Гибкая система отчётов:
- Выбор периода (по умолчанию — последние 30 дней)
- Сводка по сотрудникам (записей, часов, стоимость)
- Детализация по каждой записи

#### ⚙️ Настройки
Конфигурация системы:
- Время начала рабочего дня
- Время окончания рабочего дня
- Длительность перерыва по умолчанию

## 🗄 Структура базы данных

### Таблица employees (Сотрудники)

| Поле | Тип | Описание |
|------|-----|----------|
| id | INTEGER | Уникальный ID |
| name | TEXT | ФИО сотрудника |
| position | TEXT | Должность |
| hourly_rate | REAL | Ставка за час |
| active | INTEGER | Статус (1=активен) |
| created_at | TIMESTAMP | Дата создания |

### Таблица time_entries (Записи времени)

| Поле | Тип | Описание |
|------|-----|----------|
| id | INTEGER | Уникальный ID |
| employee_id | INTEGER | Ссылка на сотрудника |
| date | DATE | Дата |
| start_time | TIME | Время начала |
| end_time | TIME | Время окончания |
| break_minutes | INTEGER | Перерыв в минутах |
| task_description | TEXT | Описание задачи |
| project | TEXT | Проект |

### Таблица projects (Проекты)

| Поле | Тип | Описание |
|------|-----|----------|
| id | INTEGER | Уникальный ID |
| name | TEXT | Название проекта |
| color | TEXT | Цвет для визуализации |
| active | INTEGER | Статус |

## 🔧 API Endpoints

| Метод | Путь | Описание |
|-------|-----|----------|
| GET | / | Главная страница |
| POST | /login | Вход по PIN |
| GET | /logout | Выход |
| GET | /dashboard | Панель управления |
| GET | /employees | Список сотрудников |
| POST | /employees/add | Добавить сотрудника |
| GET | /employees/delete/<id> | Удалить сотрудника |
| POST | /time/add | Добавить запись времени |
| GET | /time/stop/<id> | Остановить запись |
| GET | /reports | Отчёты |
| GET | /api/stats | JSON-статистика |
| GET | /settings | Настройки |
| POST | /settings/save | Сохранить настройки |

## 🛠 Расширение системы

### Добавление нового функционала

1. Добавь новый route в `app.py`:

```python
@app.route('/new-feature')
@login_required
def new_feature():
    return render_template('new_feature.html')
```

2. Создай шаблон в `templates/`

### Изменение PIN

В файле `app.py`:

```python
ADMIN_PIN = 'твой-новый-pin'
```

## 🐛 Устранение проблем

### Ошибка "Database is locked"

```bash
# Закрой все соединения к БД и перезапусти приложение
```

### Ошибка "Port 5000 is already in use"

```python
# Измени порт в app.py
app.run(debug=True, host='0.0.0.0', port=5001)
```

### Нужно пересоздать базу данных

```bash
# Удали старую и запусти заново
rm timetrack.db
python app.py
```
