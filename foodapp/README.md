# FoodApp - Система управления общепитом

## Возможности

- 👑 **Админ**: полный доступ, дашборд, логирование
- 👨‍💼 **Менеджер**: свои клиенты, производство, заказы
- 🏢 **Клиент**: только своё меню и связь с менеджером
- 🏭 **Производство**: только свои заказы

## Запуск

```bash
cd foodapp
pip install -r requirements.txt
python main.py
```

API доступно на http://localhost:8000


## Дашборд админа
- Статистика: менеджеры, клиенты, производство
- Заказы за сегодня
- Прибыль за сегодня
- Активность пользователей
- Последние заказы
- Непрочитанные сообщения

## Дашборд менеджера
- Свои клиенты
- Свои заказы за сегодня
- Прибыль за сегодня
- Непрочитанные сообщения
- Мои последние заказы

## Безопасность
- JWT токены
- Шифрование паролей (SHA-256)
- Логирование всех действий
- Разграничение прав доступа
