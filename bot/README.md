# WorkTable Telegram Bot

## Запуск

```bash
cd bot
pip install -r requirements.txt
python3 bot.py
```

## Возможности админ-бота

### 📋 Заказы
- Просмотр всех заказов
- Фильтр по статусу (ожидают, подтверждены, отправлены)
- Подтверждение/отклонение заказов

### 👥 Партнёры
- Список всех партнёров
- Активация/деактивация
- Добавление новых

### 🍽 Меню
- Меню на сегодня
- Меню на неделю
- Добавление блюд

### 📊 Статистика
- Количество заказов по статусу
- Количество партнёров

### 📢 Рассылка
- Отправка сообщений всем партнёрам

## Команды

- `/start` - Главное меню
- `/menu` - Меню на сегодня
- `/orders` - Последние заказы
- `/stats` - Статистика

## Настройка Supabase

Добавьте переменные окружения:
```bash
export SUPABASE_URL="https://your-project.supabase.co"
export SUPABASE_KEY="your-anon-key"
```
